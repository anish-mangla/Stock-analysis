5. KEY ARCHITECTURAL DECISIONS
-------------------------------
a) Two-sleeve system (speed gets priority slots) = REJECTED
   - Normal-regime speed sleeve is negative EV
   - Wastes portfolio slots on bad trades

b) Adaptive exits + crisis override = ADOPTED
   - Crisis mode: bypass D+1<0 veto, short exits, separate risk budget
   - Normal mode: shorter exits for easy-target trades (ATR<1.0)
   - Score-weighted sizing improves capital efficiency

c) Crisis sleeve value:
   - 58-81 trades over 5.9 years (rare but profitable)
   - 69% win rate, +1.59% avg return, 1.5d avg hold
   - Adds ~1% CAGR and reduces max DD by ~1%


6. PRODUCTION SYSTEM ARCHITECTURE
-----------------------------------
Step 1: Regime check
  - If num_droppers_3pct in [61,93]: activate crisis mode
  - Else: normal mode

Step 2: Crisis mode
  - Entry: all events with ATR < 0.8 (bypass D+1<0 veto)
  - Exit: +5%/-6%/10d
  - Sizing: same as core

Step 3: Normal mode
  - Entry: current screener (CONFIDENT_YES or SMALLER_YES)
  - Exit: if ATR < 1.0 → +5%/-8%/15d; else → +5%/-8%/60d
  - Sizing: score-weighted (1.25x for score>=10, 1.0x for >=8, 0.75x else)

Step 4: Admission priority
  - Crisis trades first (when active)
  - Then core trades by score (descending)
